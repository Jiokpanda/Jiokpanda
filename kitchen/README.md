# ㄱ자 주방 3D 플랜

도면 이미지의 치수(1,850 · 2,480 · 700 등)를 기준으로 주방을 3D로 세워 본 페이지와, 양념망장을 넣을 자리 검토 메모입니다.

- `kitchen-3d.html` — three.js로 그린 3D 모델. 배치안(원안 / A / B / C)을 바꾸고, 망장·서랍을 꺼내 볼 수 있어요.

## 결론

오른쪽 벽 하부장은 쿡탑 730 + 식세기 600 + 개수대 1150으로 벽부터 코너까지 꽉 차 있어요.
개수대 구간 1150이 싱크볼(도면상 약 840)보다 넉넉하니, **개수대장을 900으로 줄이면 쿡탑 바로 옆에 200 망장**이 들어가요.

```
원안 : 쿡탑 730 | 식세기 600 | 개수대 1150            | 코너 650
A안  : 쿡탑 730 | 망장 200 | 식세기 600 | 개수대 900 | 필러 50 | 코너 650
```

| 안 | 망장 자리 | 바꿔야 하는 것 | 판단 |
|---|---|---|---|
| A | 쿡탑 바로 옆, 200 | 개수대장 1150 → 900 (싱크볼 860 이하) | 추천 |
| B | 쿡탑 아래 둘째 서랍, 730 | 없음 | 공사 변경 없이 |
| C | 쿡탑 바로 옆, 150 | 식세기 60cm → 45cm 슬림 | 식세기 용량 줄어듦 |
| D | 식세기와 개수대 사이, 200 | 개수대장 1150 → 900 | A보다 불리 |
| E | 홈바·가전장 키큰 망장 | 키큰장 내부 구성 | 여분 보관용 |
| F | 쿡탑 구간 730 쪼개기 | 인덕션 하부장 600 필요 → 남는 폭 100 남짓 | 어려움 |

## 시공사와 확인할 것

- 싱크볼 실제 규격과 최소 하부장 폭 (860 이하 볼이면 보통 900장 가능)
- 코너 필러: 코너장 쪽 필러만으로 충분하면 개수대장 950까지 가능
- A안에서 개수대 중심이 코너 쪽으로 약 75 이동 — 배수·급수 위치
- 개수대 뒤 파란 점선 X 박스가 하부장 안 설비라면 A안 식세기와 약 140 겹침
- 200 망장 바스켓 안쪽 폭(약 130~140, 제품마다 다름)과 단 높이 조절 여부

치수는 도면 이미지에서 읽은 값이라 ±20 안팎 오차가 있어요. 높이(상판 850, 상부장 아래 1,480, 천장 2,300)는 일반값입니다.
